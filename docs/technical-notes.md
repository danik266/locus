# Continue — персональный маршрут поступления

Рабочий прототип для LOCUS Startup Hackathon 2026, кейс 02. От анкеты до объяснимого подбора, сравнения и плана действий.

## Запуск

Node.js >= 22.13. `npm ci`, затем `npm run dev`. Адрес выводится в терминале. `npm run build` — production-сборка, `npm test` — проверки подбора и плана.

## Пользовательский путь

1. «Построить маршрут»: шесть шагов анкеты (о себе, академический профиль, экзамены, страны, бюджет, цели и готовность).
2. Анимированный экран анализа и отдельная диагностика: цель, сильные стороны, ограничения, главный барьер и приоритет.
3. Реальные программы выбранного направления и страны с объяснениями, ограничениями и официальными источниками.
4. Выбрать минимум две программы и сравнить их.
5. Выбрать программу, получить задачи, отметить прогресс. Изменение бюджета и английского влияет на рекомендации и подготовку.
6. Вернуться после перезагрузки через «Мой маршрут». Можно сохранить план в PDF через печать или удалить локальные данные.

## Стек и архитектура

React 19, TypeScript, vinext/Vite, CSS. `app/page.tsx` — клиентские экраны, `lib/program-catalog.ts` — каталог, `lib/admissions.ts` — правила подбора и плана, `app/globals.css` — адаптивный дизайн и объёмные CSS-модели. IntersectionObserver запускает сборку моделей один раз при появлении; `prefers-reduced-motion` отключает движение. Локальное сохранение в `localStorage` (`dalee-v1`).

## Данные и проверка

**Каталог из официальных источников:** 22 программы в семи странах, включая Computer Science в SDU University. Для программы указаны ссылки на страницы курса, приёма, стоимости и языка. Год тарифа указан отдельно; отсутствующие цены и сроки остаются пустыми. Расчёт бюджета использует тарифы для граждан Казахстана и курс Национального банка на 18 сентября 2026 года. Стоимость проживания и дополнительные сборы не входят в сравнение.

В анкете доступно 15 направлений и свободный ввод. Подтверждённые программы сейчас относятся к технологиям, бизнесу и дизайну. Для остальных направлений показывается честное пустое состояние без вымышленных вузов.

Правила ранжирования: совпадение направления и выбранной страны (фильтр), бюджет и подтверждённый IELTS. TOEFL требует проверки эквивалентности на официальном сайте. Самооценка английского A1–C2 не считается подтверждением языкового требования. Для обычного казахстанского аттестата отдельно отмечено ограничение прямого поступления в Twente. Репутация и карьерные перспективы пока не ранжируются без проверенных данных. Баллы внутренние и не отображаются как вероятность поступления. Отметки прогресса остаются в браузере. Ответы анкеты передаются серверному маршруту для AI-диагностики, а оттуда в Groq при наличии ключа; аккаунта и облачной синхронизации нет.

## AI / API / готовые компоненты

Groq подключён через серверный маршрут `app/api/diagnosis/route.ts` с ключом `GROQ_API_KEY` из `.env.local` или секрета хостинга. Модель создаёт краткое объяснение профиля, сильных сторон, ограничений и следующего шага. Основные сигналы в `lib/diagnosis.ts` и подбор остаются проверяемыми правилами. Экран загрузки ждёт реальный запрос; при ошибке показывается локальная диагностика без выдачи её за AI-ответ. GPT Images использован для дизайн-концептов в `design/` и social preview. Программирование — при помощи Codex. Базовый vinext/Sites starter предоставлен готовым; вся продуктовая логика создана в проекте. Шрифт Manrope загружается через Google Fonts; есть системный fallback. CSS-модели — код, не фотографии и не WebGL.

## Тестовый сценарий

Создать профиль: технологии, любая страна, 12 000 €, IELTS 6. Проверить программы и ссылки на источники. Выбрать Нидерланды: увидеть ограничение для обычного казахстанского аттестата. Поменять направление на дизайн — весь набор меняется. Сравнить две программы. Выбрать Twente при IELTS 5 и бюджете 5 000 € — в плане есть язык, диплом и финансирование. Отметить задачу и перезагрузить: прогресс сохраняется.

## Ограничения и следующий этап

Перед подачей нужны обновление тарифов и сроков для набора 2027/28 по мере их публикации, визуальная проверка на устройствах, доступный GitHub с историей, демо-видео до 3 минут, презентация до 8 слайдов и описание ролей команды (заполняет капитан). Реальные заявления не отправляются. Поступление не гарантируется. Локальное хранение можно потерять при очистке браузера.

## Languages

Russian is the default when no language cookie exists. The header switcher also offers EN and KK, but the new program descriptions and source notes are currently in Russian. The server uses the `continue_locale` cookie for document language, metadata and initial rendering. Changing language does not replace profile values, selected programs or completed tasks. The original `dalee-v1` storage key is retained for backward compatibility.

`lib/messages.ts` contains translations; `lib/i18n.ts` handles locale validation, currency and dynamic sentences. `app/language.tsx` localizes React text and accessibility labels without DOM mutation; form option values and event handlers remain canonical. Add new languages with complete dictionaries and coverage tests. No external translation API is used.

Automated tests cover the catalogue, recommendations, preparation tasks, dictionary coverage, locale validation and name preservation. Full translation of program data and visual browser QA remain pending.
