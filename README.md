# Continue

Персональный маршрут поступления: от интересов и выбора программы до понятного плана действий.

Проект для **LOCUS Startup Hackathon 2026**, кейс №2. Сейчас в разработке.

## Что уже есть

- Анкета абитуриента и подбор программ с объяснениями.
- Сравнение вариантов и личный план с отслеживанием прогресса.
- Интерфейс на английском, русском и казахском.
- Адаптивный дизайн и анимации при прокрутке.

Пока используются демонстрационные данные и подбор по правилам. Внешняя AI-модель не подключена; ответы и прогресс сохраняются в браузере.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Адрес локального сайта появится в терминале.

```bash
npm run build   # Сборка
npm test        # Тесты
npm run lint   # Проверка кода
```
