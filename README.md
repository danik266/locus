# Continue

Персональный маршрут поступления: от интересов и выбора программы до понятного плана действий.

Проект для **LOCUS Startup Hackathon 2026**, кейс №2. Сейчас в разработке.

## Что уже есть

- Шесть шагов анкеты: этап обучения, академический профиль, экзамены или самооценка английского A1–C2, страны, бюджет и приоритеты. Есть 15 готовых направлений и свободный ввод.
- После анкеты — отдельная диагностика профиля, затем подбор программ с объяснениями.
- Сравнение вариантов и личный план с отслеживанием прогресса.
- Интерфейс на английском, русском и казахском.
- Адаптивный дизайн и анимации при прокрутке.

В каталоге 22 реальные программы: по три в Германии, Польше, Нидерландах, США, Италии и Южной Корее, четыре в Казахстане. Для каждой есть ссылка на официальную страницу и проверенные сведения о стоимости, языке и приёме. Неопубликованные сроки и тарифы отмечены как неизвестные. Подбор работает по правилам и не создаёт вымышленных вариантов для направлений, которых нет в каталоге. Репутация и карьерные возможности собираются как приоритеты, но не влияют на оценку без проверенных данных. После анкеты сервер запрашивает Groq для кратких текстовых рекомендаций. Ключевые ограничения, подбор и план работают по прозрачным правилам; при недоступности Groq диагностика остаётся доступной. Ответы и прогресс сохраняются в браузере; для AI-диагностики ответы анкеты передаются Groq.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Для AI-диагностики добавьте `GROQ_API_KEY` в `.env.local` (файл игнорируется Git). Без ключа работает диагностика по правилам. При размещении сайта настройте `GROQ_API_KEY` как серверный секрет хостинга.

Адрес локального сайта появится в терминале.

```bash
npm run build   # Сборка
npm test        # Тесты
npm run lint   # Проверка кода
```
