# Continue

Персональный маршрут поступления: от интересов и выбора программы до понятного плана действий.

Проект для **LOCUS Startup Hackathon 2026**, кейс №2. Сейчас в разработке.

Команда: **SixSevenSquad**, 3 участника. Публичный сайт: https://continue.46.101.134.38.sslip.io. Для входа нужен доступ к указанной пользователем почте.

## Что уже есть

- Шесть шагов анкеты: этап обучения, академический профиль, экзамены или самооценка английского A1–C2, страны, бюджет и приоритеты. Есть 15 готовых направлений и свободный ввод.
- После анкеты — отдельная диагностика профиля, затем подбор программ с объяснениями.
- Сравнение вариантов и личный план с отслеживанием прогресса.
- Интерфейс на английском, русском и казахском.
- Адаптивный дизайн и анимации при прокрутке.
- Вход по email перед анкетой, личный профиль и прогресс в MongoDB.
- Отдельный каталог университетов, короткий список первых вариантов и помощник по выбранному плану.

В исходном каталоге 22 программы с официальными источниками. При доступной MongoDB сайт загружает каталог из базы; дополнительные записи отмечены как требующие проверки, а их неподтверждённые цены, сроки и языковые пороги не используются для рекомендаций. Список университетов включает вузы без добавленных программ. Подбор работает по правилам и не создаёт вымышленных вариантов. После анкеты сервер запрашивает Groq для кратких текстовых рекомендаций; при недоступности Groq диагностика остаётся доступной. Вход по email требуется перед анкетой. Профиль, выбранная программа, прогресс и переписка с помощником хранятся в MongoDB по аккаунту. Помощник получает профиль и факты программы из базы на сервере; неподтверждённые условия ему не передаются. При недоступности Groq он отвечает по правилам на частые вопросы о следующем шаге, стоимости, языке, сроках и документах. Ответы анкеты и вопрос помощнику передаются Groq только при настроенном ключе.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Добавьте в `.env.local` (или в серверное окружение при размещении) `MONGODB_URI` и случайный `SESSION_SECRET`. MongoDB должна быть доступна приложению только через локальный адрес или защищённый туннель. Для входа по email в production нужны `RESEND_API_KEY` и `MAIL_FROM` с подтверждённым доменом отправителя. Без почтового ключа коды выводятся только в консоль в development; в production отправка недоступна. Для AI-диагностики добавьте `GROQ_API_KEY`; без ключа работает диагностика по правилам.

На сервере с контейнером MongoDB можно использовать `MONGODB_URI=mongodb://127.0.0.1:27017/locus`. Для локальной разработки через SSH-туннель используйте `ssh -N -L 127.0.0.1:27018:127.0.0.1:27017 root@<server>` и `MONGODB_URI=mongodb://127.0.0.1:27018/locus`. Скрипты `db:seed` и `seed-expanded-programs.ts` изменяют базу; перед запуском проверяйте их содержимое и подключение.

Адрес локального сайта появится в терминале.

```bash
npm run build   # Сборка
npm test        # Тесты
npm run lint   # Проверка кода
```
