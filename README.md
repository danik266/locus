## 💡 О проекте

При поступлении в университет школьники и их родители сталкиваются с огромным потоком разрозненной информации: требования, дедлайны, экзамены, стоимость и визовые правила. В этом хаосе сложно понять, подходит ли программа под реальный бюджет и академический уровень, а главное — **какой конкретный шаг сделать первым**.

**Continue.** решает эту проблему, превращая неопределённость в персональную пошаговую стратегию. Сервис диагностирует цели и ограничения абитуриента, подбирает проверенные программы бакалавриата и строит интерактивный маршрут поступления с отслеживанием прогресса.

## ⚡ Ключевые возможности

### 1. 📚 Каталог программ и университетов
- База проверенных программ бакалавриата (Казахстан, Нидерланды, Великобритания, США и др.) со ссылками на официальные сайты приёмных комиссий.
- Удобная фильтрация по направлениям обучения, странам, бюджету, языковым требованиям и срокам подачи.
- Карточки университетов с фотографиями кампусов, прозрачными условиями и проверкой достоверности данных.

### 2. 📝 Интеллектуальная анкета (6 шагов)
- **Уровень и цели:** выбор года поступления, 15 готовых направлений обучения или свободный текстовый ввод.
- **Академические данные:** средний балл (GPA) с поддержкой различных шкал, профильные предметы и текущий статус обучения.
- **Английский язык:** баллы IELTS, TOEFL или объективная самооценка по шкале CEFR (от A1 до C2).
- **Бюджет и география:** годовой бюджет на обучение с конвертацией валют, предпочтительные страны или открытый поиск («Любая страна»).
- **Приоритеты:** гибкая настройка фокуса (карьера, практический опыт, престиж, стоимость).

### 3. 🧠 AI-диагностика профиля
- Автоматический анализ исходных данных через **Groq AI (Llama 3.3)**: определение сильных сторон, зон риска и ключевых ограничений (*bottlenecks*).
- Формирование персональной образовательной стратегии с чётким пониманием отправной точки.
- Отказоустойчивость: при недоступности внешнего AI включается детерминированная экспертная диагностика по правилам.

### 4. 🎯 Умный подбор программ (Smart Matching)
- Ранжирование программ под уникальные параметры пользователя (бюджет, язык, академический профиль).
- Прозрачные объяснения для каждой программы: блок **«Почему подходит»** и предупреждения **«Что нужно проверить или подтянуть»**.

### 5. ⚖️ Сравнение программ
- Возможность выбрать до 3 программ и сопоставить их бок о бок.
- Сравнение стоимости, требований к языку, условий отбора и рисков.
- Интеллектуальный **AI-вердикт**, помогающий взвесить альтернативы и сделать обоснованный выбор.

### 6. 🗺️ Интерактивная дорожная карта (Мой план)
- Пошаговый маршрут из **8 ключевых этапов**: от подтверждения пути поступления до финальной подачи документов и первого дня учёбы.
- Интерактивный чек-лист с сохранением выполненных шагов и расчётом процента готовности.
- Генерация персональных подзадач под выбранный вуз с помощью AI.
- Возможность экспорта плана в **PDF** для печати или сохранения.

### 7. 💬 Встроенный AI-ассистент
- Контекстный помощник по поступлению, знающий выбранную программу и анкету пользователя.
- Отвечает на вопросы по дедлайнам, подготовке к экзаменам, документам и финансовым нюансам.

### 8. 🔐 Беспарольная аутентификация и облачная синхронизация
- Вход по Email с одноразовым 6-значным OTP-кодом (через **Resend API**) — без необходимости запоминать пароли.
- Автоматическое сохранение анкеты, выбранных программ и отметок прогресса в базе данных **MongoDB**.
- Доступ к своему плану с любого устройства.

### 9. 🌐 Полная мультиязычность
- Полная локализация интерфейса на 3 языка: **Русский**, **Қазақша** и **English**.

### 10. 🎨 Премиальный UX/UI
- Современная типографика, продуманная адаптивная вёрстка для смартфонов, планшетов и десктопов.
- Мгновенная плавная загрузка без мерцания страниц и лишних экранов ожидания.

## 🚀 Локальный запуск

### Требования
- Node.js `22.13.0` или новее
- npm `10+`
- Доступ к MongoDB (локально или через MongoDB Atlas)

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/danik266/locus.git
cd locus
npm ci
```

### 2. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:
```env
# Подключение к базе данных
MONGODB_URI=mongodb://127.0.0.1:27017/locus

# Секрет для сессий
SESSION_SECRET=your-random-secret-key-at-least-32-chars

# Отправка email (Resend)
RESEND_API_KEY=re_your_resend_api_key
MAIL_FROM=Continue <login@yourdomain.com>

# AI-диагностика и персональный план (Groq)
GROQ_API_KEY=gsk_your_groq_api_key
```
> *Примечание: в режиме разработки при отсутствии `RESEND_API_KEY` одноразовые OTP-коды выводятся прямо в консоль терминала.*

### 3. Запуск dev-сервера
```bash
npm run dev
```
Откройте в браузере [http://localhost:3000](http://localhost:3000).

### 4. Проверка и тесты
```bash
npm run build   # Сборка production-билда
npm test        # Запуск тестов
npm run lint    # Проверка кода линтером
```
